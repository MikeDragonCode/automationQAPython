# 0.1. Переменные, типы данных, type() и id()

## Зачем это нужно

Любой тест начинается с данных: логин, пароль, ожидаемый статус-код, тестовый ID. Всё это — переменные. Прежде чем писать `assert`, нужно понимать, что на самом деле происходит, когда ты пишешь `x = 5`, и почему `a = b` в Python — это не копирование значения, а нечто другое. Ошибки, связанные с этим непониманием, — одна из самых частых причин "тест ведёт себя не так, как я ожидал".

## Теория

### Переменная — это имя для значения

Переменная в Python создаётся в момент присваивания — никаких отдельных объявлений типа не нужно:

```python
username = "mike_qa"
```

Слева — имя, справа — значение, `=` их связывает. Присваивать можно заново сколько угодно раз, старое значение просто забывается.

### Основные типы данных

У каждого значения есть тип — он определяет, что со значением можно делать (сложить два числа можно, а число со строкой — нет). В Python есть несколько базовых встроенных типов, с которыми ты будешь работать постоянно:

| Тип | Что это | Пример |
|---|---|---|
| `int` | целое число | `age = 25` |
| `float` | дробное число | `price = 19.99` |
| `str` | строка (текст) | `name = "Mike"` |
| `bool` | логическое значение | `is_active = True` |
| `list` | список — упорядоченный набор значений, можно менять | `tags = ["smoke", "regression"]` |
| `tuple` | кортеж — как список, но неизменяемый | `point = (10, 20)` |
| `dict` | словарь — пары "ключ: значение" | `user = {"id": 1, "name": "Mike"}` |
| `set` | множество — набор уникальных значений без порядка | `ids = {1, 2, 3}` |
| `NoneType` | отсутствие значения | `result = None` |

Не пугайся, если пока не всё понятно из одной строчки таблицы — числам, строкам, спискам и словарям посвящены отдельные уроки дальше в этой неделе, там разберём каждый тип подробно с операциями и методами. Здесь важно другое: увидеть, что типов немного, они простые, и любая переменная в твоём тесте — это всегда что-то из этого списка.

JSON, с которым ты постоянно будешь работать в API-тестах, устроен ровно из этих типов: объект JSON — это `dict`, массив — это `list`, строка — `str`, число — `int`/`float`, `true`/`false` — `bool`, `null` — `None`. То есть JSON — это не что-то новое, а просто способ записать те же типы данных текстом.

### Переменная — это ссылка на объект

Важная деталь, без которой поведение Python иногда будет казаться странным: переменная — это не "коробка со значением", а **ссылка на объект**. Когда ты пишешь:

```python
user_id = 42
```

Python создаёт объект-число `42` где-то в памяти, а переменная `user_id` — это просто именованная ссылка на него. Отсюда важное следствие: если присвоить одну переменную другой,

```python
a = [1, 2, 3]
b = a
```

то `a` и `b` указывают на один и тот же объект. Изменишь список через `b` — увидишь изменение и через `a` (подробнее об этом — в уроке про списки, там это критично; для чисел и строк разница не так заметна, потому что они неизменяемые).

Тип переменной определяется не в момент объявления, а в момент присваивания значения — это называется **динамической типизацией**. Одна и та же переменная в течение программы может ссылаться сначала на число, потом на строку:

```python
value = 5
value = "теперь я строка"
```

Так поступать в реальном коде не стоит (это сбивает с толку), но знать, что Python это позволяет, важно.

Узнать тип объекта, на который ссылается переменная, можно функцией `type()`:

```python
print(type(user_id))   # <class 'int'>
```

А узнать идентификатор объекта в памяти — функцией `id()`. Она пригодится, когда нужно проверить, ссылаются ли две переменные на один и тот же объект или на разные:

```python
print(id(a) == id(b))  # True, если a и b — одна и та же ссылка
```

Python поддерживает **множественное присваивание** (каждая переменная получает свой объект) и **каскадное** (все переменные ссылаются на один и тот же объект):

```python
a, b = 1, 2          # множественное — разные объекты
x = y = 0             # каскадное — общий объект
a, b = b, a           # классический обмен значениями без временной переменной
```

### Имена переменных

Правила простые: имя начинается с буквы или `_`, дальше могут идти буквы, цифры и `_`. Регистр важен: `user` и `User` — разные переменные. Нельзя использовать ключевые слова (`if`, `class`, `True` и т.п.) и не стоит переопределять имена встроенных функций (`print`, `list`, `id`) — это молча "сломает" их для остальной программы.

Договорённость по стилю (PEP8), которой стоит следовать сразу: имена переменных — `snake_case`, осмысленные, отражающие суть данных: `expected_status`, `response_body`, а не `x`, `tmp2`.

## Пример

```python
# типичные переменные тестового скрипта
base_url = "https://api.example.com"
user_id = 42
is_active = True
expected_status = 200

print(type(base_url), type(user_id), type(is_active))
# <class 'str'> <class 'int'> <class 'bool'>

# каскадное присваивание — общий счётчик для нескольких переменных
retries_left = max_retries = 3
print(id(retries_left) == id(max_retries))  # True
```

## Частые ошибки

- Путать `=` (присваивание) и `==` (сравнение) — придёт позже, но ошибка настолько частая, что стоит запомнить сразу.
- Обращаться к переменной до её создания ("сначала присвоить, потом использовать" — работает только в этом порядке).
- Давать переменным имена встроенных функций (`list = [1, 2, 3]`), после чего `list()` перестаёт работать в этом файле.
- Ожидать, что `a = b` создаёт копию данных — для изменяемых типов (списки, словари) это не так.

## Мини-задания

1. **Разминка.** Заведи пять переменных, описывающих тестового пользователя: `username` (str), `age` (int), `email` (str), `is_admin` (bool), `balance` (число) — подбери подходящие значения. Выведи на экран каждую переменную и её тип с помощью `type()`.
2. **Основное.** Создай список `original = [1, 2, 3]`, присвой `alias = original` (без копирования), добавь в `alias` число `4` методом `.append()`. Проверь, что изменение видно и через `original`, и через `id()` убедись, что `original` и `alias` — одна и та же ссылка.
3. **Ближе к практике.** В тестах часто нужно несколько счётчиков попыток с одинаковым стартовым значением. Через каскадное присваивание создай `attempt_1 = attempt_2 = attempt_3 = 0` и проверь функцией `id()`, что все три переменные ссылаются на один и тот же объект.
4. **Со звёздочкой.** Заведи `x = 10`, присвой `y = x`, затем измени `y = 20` — убедись, что `x` не изменился (числа неизменяемы). Теперь заведи `list_a = [1, 2]`, присвой `list_b = list_a`, вызови `list_b.append(99)` — убедись, что `list_a` изменился тоже (списки изменяемы, присваивание — не копия). Объясни себе словами, почему поведение разное.
