# 0.7. Словари, кортежи и множества

## Зачем это нужно

Тело JSON-ответа API — это, по сути, словарь Python (мы явно свяжем это в модуле 3, но структура та же уже сейчас). Кортежи используются там, где данные не должны меняться (например, фиксированные тестовые константы), а множества — там, где важна уникальность и быстрая проверка "есть ли значение в наборе". Без этих трёх коллекций читать реальный тестовый код будет тяжело.

## Теория

### Словари: создание и доступ по ключу

Словарь (`dict`) — ассоциативный массив: значения хранятся не по числовому индексу, а по ключу.

```python
user = {"id": 1, "username": "ivan", "is_active": True}
user["username"]           # 'ivan'
user["email"]              # KeyError! такого ключа нет
```

Ключами могут быть только неизменяемые типы (строки, числа, кортежи), значениями — что угодно, включая вложенные списки и другие словари.

### Безопасный доступ: .get()

Обращение по `[]` к несуществующему ключу роняет программу с `KeyError`. Метод `.get()` вместо этого возвращает `None` (или значение по умолчанию, если его указать вторым аргументом) — и код не падает:

```python
user.get("email")            # None — безопасный доступ, без ошибки
user.get("email", "n/a")     # 'n/a' — значение по умолчанию
user.get("username", "n/a")  # 'ivan' — ключ есть, значение по умолчанию не используется
```

Правило простое: если есть шанс, что ключа может не быть (например, поле необязательно в API-ответе), используй `.get()`, а не `[]`.

### Изменение словаря и перебор

Словарь — изменяемый тип: можно добавлять, менять и удалять пары ключ-значение:

```python
user["email"] = "ivan@example.com"   # добавили новый ключ (или перезаписали, если уже был)
del user["is_active"]                 # удалили ключ
```

Перебор словаря чаще всего делают через `.items()`, чтобы сразу получить и ключ, и значение:

```python
for key, value in user.items():
    print(key, value)
```

Есть ещё `.keys()` (только ключи) и `.values()` (только значения) — если значение не нужно, `.keys()` читается чуть яснее, чем `.items()` с игнорируемой переменной.

### Кортежи (tuple)

Как список, но **неизменяемый**:

```python
point = (10, 20)
point[0] = 5   # ошибка — кортеж нельзя менять
```

Зачем нужны, если есть списки? Во-первых, неизменяемость иногда — гарантия, что данные случайно не испортят по ходу программы. Во-вторых, кортеж (в отличие от списка) можно использовать как ключ словаря. В-третьих, функция может вернуть сразу несколько значений именно через кортеж:

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)   # неявно создаётся кортеж

low, high = get_min_max([3, 1, 4, 1, 5])
```

### Множества (set)

Неупорядоченная коллекция **уникальных** значений:

```python
cities = {"Moscow", "Tver", "Moscow", "Ufa"}
print(cities)   # {'Moscow', 'Tver', 'Ufa'} — дубликат исчез
```

Отличный инструмент, чтобы быстро убрать дубликаты из списка: `unique = set(some_list)`. Пустое множество нельзя создать через `{}` — это создаст словарь. Нужно писать `set()`.

### Операции над множествами: пересечение, объединение, разность

Множества поддерживают операции пересечения (`&`), объединения (`|`) и разности (`-`) — удобно, например, сравнить, какие тестовые ID есть в одном прогоне, но отсутствуют в другом:

```python
run_1 = {1, 2, 3, 4}
run_2 = {3, 4, 5, 6}

print(run_1 & run_2)   # {3, 4} — пересечение: есть в обоих прогонах
print(run_1 | run_2)   # {1, 2, 3, 4, 5, 6} — объединение: есть хотя бы в одном
print(run_1 - run_2)   # {1, 2} — разность: есть в run_1, но нет в run_2
```

### Comprehension для множеств и словарей

По аналогии со списками (см. прошлый урок) можно строить множества и словари в одну строку:

```python
unique_lengths = {len(city) for city in cities}          # множество
lengths_by_city = {city: len(city) for city in cities}   # словарь
```

## Пример

```python
response = {
    "status": "ok",
    "data": {"id": 1, "name": "Test User"},
    "errors": [],
}

print(response.get("status"))              # ok
print(response.get("message", "no message"))  # no message — ключа нет, но ошибки не будет

user_ids_run_1 = {1, 2, 3, 4}
user_ids_run_2 = {3, 4, 5, 6}

missing_in_run_2 = user_ids_run_1 - user_ids_run_2
print(missing_in_run_2)   # {1, 2}

STATUS_LABELS = {
    200: "OK",
    404: "Not Found",
    500: "Server Error",
}
print(STATUS_LABELS.get(403, "Unknown status"))  # Unknown status
```

## Частые ошибки

- Обращаться к несуществующему ключу через `d[key]` вместо безопасного `d.get(key)` — падает `KeyError` там, где можно было аккуратно обработать отсутствие значения.
- Пытаться создать пустое множество через `{}` — получится словарь.
- Пытаться изменить кортеж и удивляться ошибке — это его основное назначение.
- Полагаться на порядок элементов множества — `set` не гарантирует порядок (в отличие от списка и, начиная с Python 3.7, словаря).

## Мини-задания

1. **Разминка.** Дан словарь `config = {"base_url": "https://api.example.com", "timeout": 30}`. Через `.get()` сохрани в `timeout` значение по ключу `"timeout"` (оно есть), а в `retries` — значение по ключу `"retries"` с значением по умолчанию `3` (такого ключа в словаре нет).
2. **Основное.** Дан кортеж `point = (10, 20)`. Распакуй его в переменные `x` и `y`. Дан список с повторами `visited_pages = ["home", "cart", "home", "checkout", "cart"]` — преврати его в множество `unique_pages` без дубликатов и сохрани в `pages_count` количество уникальных страниц.
3. **Ближе к практике.** Есть ID тестов, упавших в двух последних прогонах: `run_1_failed = {"test_login", "test_cart", "test_search"}` и `run_2_failed = {"test_cart", "test_checkout"}`. Сохрани в `still_failing` тесты, упавшие в обоих прогонах (пересечение), а в `fixed_since_run_1` — тесты, упавшие в первом прогоне, но не во втором (значит, почти наверняка исправлены).
4. **Со звёздочкой.** Заведи `empty_set = set()` и `empty_dict = {}` — и через `type()` сохрани в `empty_set_type` и `empty_dict_type` строковые имена их типов (`type(x).__name__`), чтобы явно увидеть, что `{}` — это `dict`, а не пустое множество. Отдельно: дан словарь `settings = {"retries": 0}`. Сравни `settings.get("retries", 5)` (сохрани в `value_with_default`) со значением, которое было бы, если бы ключа `"retries"` не было вовсе — обе ситуации выглядят разными, но `.get()` с default срабатывает **только** при отсутствии ключа, а не при "пустом" значении.

## Домашнее задание

Дан список результатов тестового прогона в виде списка словарей:

```python
run_results = [
    {"test": "test_login", "status": "passed", "duration_ms": 120},
    {"test": "test_logout", "status": "passed", "duration_ms": 95},
    {"test": "test_registration", "status": "failed", "duration_ms": 340},
    {"test": "test_password_reset", "status": "failed", "duration_ms": 210},
    {"test": "test_profile_update", "status": "passed", "duration_ms": 150},
]
```

Напиши скрипт, который:

1. Считает и выводит количество тестов со статусом `passed` и `failed`.
2. Собирает в список названия всех упавших тестов (`failed`).
3. Считает суммарное и среднее время выполнения (`duration_ms`) по всем тестам, округлённое до целого.
4. Выводит итоговую сводку в формате:
   ```
   Passed: 3, Failed: 2
   Failed tests: test_registration, test_password_reset
   Total duration: 915 ms, average: 183 ms
   ```

**Критерии готово**: скрипт запускается без ошибок командой `python homework_week1.py`, использует хотя бы один генератор списков и словарь `.get()` там, где это уместно, вывод точно соответствует формату из примера (числа могут отличаться, если ты меняешь исходные данные для проверки).
