# 0.6. Циклы и генераторы списков

## Зачем это нужно

Прогнать проверку по списку из 50 тестовых пользователей, подождать (с ограничением по попыткам), пока элемент появится на странице, отфильтровать только упавшие тесты из общего списка результатов — всё это циклы. List comprehension (генератор списков) — идиома, которую ты будешь видеть в почти любом чужом Python-коде, включая тестовые фреймворки.

## Теория

### while

Выполняется, пока условие истинно. Хорош для ситуаций, когда заранее не известно число повторений — например, ожидание с ретраями:

```python
attempts = 0
max_attempts = 5
success = False

while attempts < max_attempts and not success:
    attempts += 1
    success = try_something()  # условная функция, которую напишем позже
```

Если забыть увеличить счётчик (`attempts += 1`) или изменить условие, цикл `while` будет выполняться бесконечно — это одна из самых частых ошибок новичков, из-за которой "скрипт завис".

### break, continue и else в циклах

`break` прерывает цикл досрочно — например, когда искомое уже найдено и продолжать перебор бессмысленно:

```python
target = "test_registration"
for name in ["test_login", "test_registration", "test_logout"]:
    if name == target:
        print("нашли!")
        break   # дальше можно не проверять
```

`continue` пропускает оставшуюся часть текущей итерации и сразу переходит к следующей — удобно, чтобы не наращивать вложенность через `if`:

```python
for status in [200, 404, 200, 500]:
    if status == 200:
        continue   # успешные пропускаем, дальше код не выполняется для них
    print(f"проблема: {status}")
```

У циклов (и `while`, и `for`) есть необязательный блок `else` — он выполняется, только если цикл завершился "штатно" (по условию или перебору до конца), а не через `break`. На практике используется редко, но встречается в чужом коде, поэтому знать про него стоит.

### for и range

`for` перебирает элементы **итерируемого объекта** — списка, строки, результата `range()`:

```python
for i in range(5):        # 0, 1, 2, 3, 4 — верхняя граница не включается
    print(i)

for user in users_list:
    print(user)
```

### enumerate()

Когда внутри цикла нужен не только элемент, но и его индекс, `enumerate()` даёт их сразу вместе — это удобнее, чем городить отдельный счётчик вручную:

```python
users_list = ["Ivan", "Olga", "Petr"]

for index, user in enumerate(users_list):
    print(index, user)
# 0 Ivan
# 1 Olga
# 2 Petr
```

### zip(): перебор двух списков одновременно

Когда нужно сравнить элементы двух списков "по позициям" — например, ожидаемые и фактические результаты теста — `zip()` соединяет их в пары, по одной с каждой стороны:

```python
expected = [200, 200, 404]
actual = [200, 500, 404]

for exp, act in zip(expected, actual):
    if exp != act:
        print(f"mismatch: expected {exp}, got {act}")
# mismatch: expected 200, got 500
```

Если списки разной длины, `zip()` останавливается по самому короткому — лишние элементы длинного списка молча игнорируются, об этом стоит помнить.

### List comprehension (генератор списков)

Компактная запись цикла, который строит новый список:

```python
squares = [x ** 2 for x in range(5)]
# эквивалент:
# squares = []
# for x in range(5):
#     squares.append(x ** 2)
```

Можно добавить условие фильтрации:

```python
failed_only = [name for name, passed in test_results if not passed]
```

Синтаксис: `[<что положить в список> for <переменная> in <источник> if <условие>]`. Часть `if` — необязательна. Такая запись работает быстрее обычного цикла и считается более "питоничной", но злоупотреблять ей не стоит: если выражение перестаёт помещаться в одну понятную строку — лучше вернуться к обычному циклу `for`.

## Пример

```python
test_results = [
    ("test_login", True),
    ("test_logout", True),
    ("test_registration", False),
    ("test_password_reset", False),
]

# обычный цикл: печатаем только упавшие тесты
for name, passed in test_results:
    if not passed:
        print(f"FAILED: {name}")

# то же самое — генератор списков, если нужен именно список имён
failed_tests = [name for name, passed in test_results if not passed]
print(failed_tests)
# ['test_registration', 'test_password_reset']

# ретрай с ограничением попыток
attempts = 0
max_attempts = 3
found = False

while attempts < max_attempts and not found:
    attempts += 1
    print(f"Attempt {attempts}: checking...")
    found = attempts == 3  # условно "получилось" на третьей попытке

print("Found!" if found else "Gave up.")
```

## Частые ошибки

- Забыть увеличить счётчик в `while` — бесконечный цикл, который "подвешивает" скрипт.
- Перепутать `range(5)` (числа 0–4) с "числами от 1 до 5" — верхняя граница `range()` не включается.
- Изменять список, по которому в этот момент итерируешься через `for` (`for x in lst: lst.remove(x)`) — элементы будут пропущены непредсказуемым образом, потому что после удаления индексы оставшихся элементов сдвигаются, а цикл этого "не замечает".
- Писать генератор списков с тремя вложенными условиями и двумя `for` "для краткости" — такой код сложнее читать, чем обычный цикл.

## Мини-задания

1. **Разминка.** С помощью генератора списков построй список `cubes` — кубы чисел от `0` до `4` включительно (`x ** 3`).
2. **Основное.** Дан список чисел `response_codes = [200, 404, 200, 500, 301, 200, 403]`. С помощью генератора списков получи список только "успешных" кодов (200–299) в `successful_codes`. Отдельно — обычным циклом `for` с `enumerate()` — собери в список `error_lines` строки `"index: code"` для каждого элемента, у которого код больше или равен 400.
3. **Ближе к практике.** Даны ожидаемые и фактические результаты одного тестового прогона: `expected = [200, 200, 404, 200]` и `actual = [200, 500, 404, 200]`. С помощью `zip()` в цикле `for` собери список `mismatches` из строк вида `"expected 200, got 500"` — только для тех позиций, где значения не совпали.
4. **Со звёздочкой.** Дан список `numbers = [1, 2, 2, 3, 4, 2, 5]`, из которого нужно убрать все вхождения числа `2`. Удалять элементы через `.remove()` внутри `for x in numbers:` — классическая ошибка (элементы пропускаются из-за сдвига индексов при удалении). Вместо этого построй новый список `cleaned` через генератор списков, оставив в нём только элементы, не равные `2`, не трогая исходный `numbers` в процессе.
