# 0.6. Циклы и генераторы списков

## Зачем это нужно

Прогнать проверку по списку из 50 тестовых пользователей, подождать (с ограничением по попыткам), пока элемент появится на странице, отфильтровать только упавшие тесты из общего списка результатов — всё это циклы. List comprehension (генератор списков) — идиома, которую ты будешь видеть в почти любом чужом Python-коде, включая тестовые фреймворки.

## Теория

### while

Выполняется, пока условие истинно. Хорош для ситуаций, когда заранее не известно число повторений — например, ожидание с ретраями:

```python
attempts = 0
max_attempts = 5
success = False

while attempts < max_attempts and not success:
    attempts += 1
    success = try_something()  # условная функция, которую напишем позже
```

`break` прерывает цикл досрочно, `continue` пропускает оставшуюся часть текущей итерации и переходит к следующей. У циклов (и `while`, и `for`) есть необязательный блок `else` — он выполняется, только если цикл завершился "штатно" (по условию), а не через `break`. На практике используется редко, но встречается в чужом коде, поэтому знать про него стоит.

### for и range

`for` перебирает элементы **итерируемого объекта** — списка, строки, результата `range()`:

```python
for i in range(5):        # 0, 1, 2, 3, 4 — верхняя граница не включается
    print(i)

for user in users_list:
    print(user)
```

`enumerate()` даёт одновременно индекс и значение — удобнее, чем городить отдельный счётчик:

```python
for index, user in enumerate(users_list):
    print(index, user)
```

### List comprehension (генератор списков)

Компактная запись цикла, который строит новый список:

```python
squares = [x ** 2 for x in range(5)]
# эквивалент:
# squares = []
# for x in range(5):
#     squares.append(x ** 2)
```

Можно добавить условие фильтрации:

```python
failed_only = [name for name, passed in test_results if not passed]
```

Синтаксис: `[<что положить в список> for <переменная> in <источник> if <условие>]`. Часть `if` — необязательна. Такая запись работает быстрее обычного цикла и считается более "питоничной", но злоупотреблять ей не стоит: если выражение перестаёт помещаться в одну понятную строку — лучше вернуться к обычному циклу `for`.

## Пример

```python
test_results = [
    ("test_login", True),
    ("test_logout", True),
    ("test_registration", False),
    ("test_password_reset", False),
]

# обычный цикл: печатаем только упавшие тесты
for name, passed in test_results:
    if not passed:
        print(f"FAILED: {name}")

# то же самое — генератор списков, если нужен именно список имён
failed_tests = [name for name, passed in test_results if not passed]
print(failed_tests)
# ['test_registration', 'test_password_reset']

# ретрай с ограничением попыток
attempts = 0
max_attempts = 3
found = False

while attempts < max_attempts and not found:
    attempts += 1
    print(f"Attempt {attempts}: checking...")
    found = attempts == 3  # условно "получилось" на третьей попытке

print("Found!" if found else "Gave up.")
```

## Частые ошибки

- Забыть увеличить счётчик в `while` — бесконечный цикл, который "подвешивает" скрипт.
- Перепутать `range(5)` (числа 0–4) с "числами от 1 до 5" — верхняя граница `range()` не включается.
- Изменять список, по которому в этот момент итерируешься через `for` (`for x in lst: lst.remove(x)`) — элементы будут пропущены непредсказуемым образом.
- Писать генератор списков с тремя вложенными условиями и двумя `for` "для краткости" — такой код сложнее читать, чем обычный цикл.

## Мини-задание

Дан список чисел `response_codes = [200, 404, 200, 500, 301, 200, 403]`. С помощью генератора списков получи список только "успешных" кодов (200–299). Отдельно — обычным циклом `for` с `enumerate()` — выведи `"index: code"` для каждого элемента, у которого код больше или равен 400.
