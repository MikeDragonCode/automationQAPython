# 0.3. Строки: индексы, срезы, методы, f-строки

## Зачем это нужно

Тексты ошибок, тела ответов API, URL, логи — почти всё, с чем сталкивается QA automation engineer на старте, представлено строками. Умение вырезать нужный кусок строки, склеить сообщение об ошибке или отформатировать URL с параметрами — база, без которой не напишешь ни одного полезного скрипта.

## Теория

Строка задаётся в одинарных или двойных кавычках — разницы нет, кроме удобства (если внутри текста есть кавычки одного вида, снаружи используй другой). Тройные кавычки (`'''` или `"""`) позволяют задавать многострочный текст.

Строки в Python — **неизменяемый** тип данных: нельзя поменять символ по индексу (`s[0] = "H"` вызовет ошибку). Любая "модификация" строки на самом деле создаёт новую строку.

### Индексы и срезы

Каждый символ строки имеет номер (индекс), начиная с `0`. Отрицательные индексы считают с конца:

```python
s = "hello python"
s[0]     # 'h'
s[-1]    # 'n'
```

Срез `s[start:stop:step]` вырезает подстроку от `start` до `stop` (не включая `stop`), с шагом `step`:

```python
s[0:5]    # 'hello'
s[:5]     # то же самое
s[6:]     # 'python'
s[::-1]   # разворот строки: 'nohtyp olleh'
```

### Основные методы

| Метод | Что делает |
|---|---|
| `.upper()` / `.lower()` | регистр |
| `.strip()` / `.lstrip()` / `.rstrip()` | удаление пробелов и переносов строк по краям |
| `.split(sep)` | разбить строку на список по разделителю |
| `.join(list)` | собрать список строк в одну через разделитель |
| `.replace(old, new)` | замена подстроки |
| `.find(sub)` | индекс первого вхождения, `-1` если не найдено |
| `.startswith(...)` / `.endswith(...)` | проверка начала/конца строки |
| `.isdigit()` / `.isalpha()` | проверка состава строки |

Методы **не изменяют** исходную строку — они возвращают новую. `s.upper()` без присваивания результата ни на что не влияет.

### Форматирование строк

Самый удобный способ — **f-строки** (с версии Python 3.6): перед кавычками ставится `f`, а внутри `{}` можно писать любое выражение Python.

```python
name = "Sergey"
age = 35
print(f"User {name}, age {age}, next year: {age + 1}")
```

До f-строк использовался метод `.format()` — иногда он всё ещё встречается в чужом коде:

```python
"User {0}, age {1}".format(name, age)
```

## Пример

```python
log_line = "  2024-01-15 12:30:01 ERROR failed to connect  "

# приводим строку в порядок и разбираем на части
clean_line = log_line.strip()
parts = clean_line.split(" ", maxsplit=2)
date, time, message = parts

print(f"[{date} {time}] {message}")
# [2024-01-15 12:30:01 ERROR failed to connect]

base_url = "https://api.example.com"
endpoint = "users"
user_id = 42
full_url = f"{base_url}/{endpoint}/{user_id}"
print(full_url)
# https://api.example.com/users/42
```

## Частые ошибки

- Забывать, что строки неизменяемы, и пытаться менять символ по индексу.
- Вызывать метод и не сохранять результат: `s.strip()` без `s = s.strip()` ничего не меняет в `s`.
- Путать `.find()` (вернёт `-1`, если не нашёл) и `.index()` (вызовет ошибку, если не нашёл).
- Склеивать строки через `+` там, где f-строка читается в разы понятнее.
- Забывать `.strip()` перед сравнением строк, считанных из файла или ввода — лишний `\n` на конце ломает сравнение.

## Мини-задание

Дана строка `"user@example.com:Qwerty123"`. Раздели её на email и пароль (разделитель — `:`). Проверь, что email содержит символ `@` и хотя бы одну точку после него. Собери и выведи сообщение через f-строку: `"Login: <email>, password length: <N>"`.
