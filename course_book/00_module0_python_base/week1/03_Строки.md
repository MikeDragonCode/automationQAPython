# 0.3. Строки: индексы, срезы, методы, f-строки

## Зачем это нужно

Тексты ошибок, тела ответов API, URL, логи — почти всё, с чем сталкивается QA automation engineer на старте, представлено строками. Умение вырезать нужный кусок строки, склеить сообщение об ошибке или отформатировать URL с параметрами — база, без которой не напишешь ни одного полезного скрипта.

## Теория

### Кавычки и многострочные строки

Строка задаётся в одинарных или двойных кавычках — разницы нет, кроме удобства (если внутри текста есть кавычки одного вида, снаружи используй другой):

```python
name = 'Ivan'
message = "He said: 'test failed'"
```

Тройные кавычки (`'''` или `"""`) позволяют задавать многострочный текст прямо как есть, с переносами строк:

```python
error_report = """Test: test_login
Status: FAILED
Reason: timeout
"""
```

### Строки неизменяемы

Строка в Python — **неизменяемый** тип данных: нельзя поменять символ по индексу.

```python
s = "hello"
s[0] = "H"   # TypeError: 'str' object does not support item assignment
```

Любая "модификация" строки на самом деле создаёт новую строку, а старая просто перестаёт быть кому-либо нужна:

```python
s = "hello"
s = "H" + s[1:]   # это не изменение s, а создание новой строки и переприсваивание
print(s)          # Hello
```

### Индексы и срезы

Каждый символ строки имеет номер (индекс), начиная с `0`. Отрицательные индексы считают с конца:

```python
s = "hello python"
s[0]     # 'h'
s[-1]    # 'n'
```

Срез `s[start:stop:step]` вырезает подстроку от `start` до `stop` (не включая `stop`), с шагом `step`:

```python
s[0:5]    # 'hello'
s[:5]     # то же самое
s[6:]     # 'python'
s[::-1]   # разворот строки: 'nohtyp olleh'
```

### Длина и проверка вхождения: len(), in

`len()` возвращает количество символов, а оператор `in` проверяет, встречается ли подстрока внутри строки — без него пришлось бы вручную писать поиск через `.find()`:

```python
log_line = "2024-01-15 ERROR failed to connect"

print(len(log_line))        # 35
print("ERROR" in log_line)  # True
print("DEBUG" in log_line)  # False
```

Это самый частый способ быстро проверить, что нужное слово (например, код ошибки или ключевое слово) вообще присутствует в тексте, прежде чем вырезать из него что-то срезом.

### Основные методы

| Метод | Что делает |
|---|---|
| `.upper()` / `.lower()` | регистр |
| `.strip()` / `.lstrip()` / `.rstrip()` | удаление пробелов и переносов строк по краям |
| `.split(sep)` | разбить строку на список по разделителю |
| `.join(list)` | собрать список строк в одну через разделитель |
| `.replace(old, new)` | замена подстроки |
| `.find(sub)` | индекс первого вхождения, `-1` если не найдено |
| `.startswith(...)` / `.endswith(...)` | проверка начала/конца строки |
| `.isdigit()` / `.isalpha()` | проверка состава строки |

Методы **не изменяют** исходную строку — они возвращают новую. `s.upper()` без присваивания результата ни на что не влияет:

```python
raw = "  Login Failed  "
clean = raw.strip().lower()   # методы можно вызывать цепочкой, друг за другом
print(clean)                  # 'login failed'
print(raw)                    # осталась той же — методы не тронули исходную строку
```

### Форматирование строк

Самый удобный способ — **f-строки** (с версии Python 3.6): перед кавычками ставится `f`, а внутри `{}` можно писать любое выражение Python.

```python
name = "Sergey"
age = 35
print(f"User {name}, age {age}, next year: {age + 1}")
```

До f-строк использовался метод `.format()` — иногда он всё ещё встречается в чужом коде:

```python
"User {0}, age {1}".format(name, age)
```

Внутри `{}` можно также указать **спецификатор формата** через `:` — например, чтобы округлить дробное число прямо при выводе, без отдельного вызова `round()`:

```python
duration_sec = 1.23456
print(f"Duration: {duration_sec:.2f} sec")   # Duration: 1.23 sec
```

`:.2f` значит "вывести как дробное число с двумя знаками после запятой" — удобно для отчётов и логов, где не нужна лишняя точность.

## Пример

```python
log_line = "  2024-01-15 12:30:01 ERROR failed to connect  "

# приводим строку в порядок и разбираем на части
clean_line = log_line.strip()
parts = clean_line.split(" ", maxsplit=2)
date, time, message = parts

print(f"[{date} {time}] {message}")
# [2024-01-15 12:30:01 ERROR failed to connect]

base_url = "https://api.example.com"
endpoint = "users"
user_id = 42
full_url = f"{base_url}/{endpoint}/{user_id}"
print(full_url)
# https://api.example.com/users/42
```

## Частые ошибки

- Забывать, что строки неизменяемы, и пытаться менять символ по индексу.
- Вызывать метод и не сохранять результат: `s.strip()` без `s = s.strip()` ничего не меняет в `s`.
- Путать `.find()` (вернёт `-1`, если не нашёл) и `.index()` (вызовет ошибку, если не нашёл).
- Склеивать строки через `+` там, где f-строка читается в разы понятнее.
- Забывать `.strip()` перед сравнением строк, считанных из файла или ввода — лишний `\n` на конце ломает сравнение.

## Мини-задания

1. **Разминка.** Дана строка `text = "automation testing"`. Сохрани в `first_word` первые 10 символов (срезом), в `last_char` — последний символ, в `reversed_text` — строку, развёрнутую задом наперёд (тоже срезом).
2. **Основное.** Дана строка `"user@example.com:Qwerty123"`. Раздели её на email и пароль (разделитель — `:`). Проверь, что email содержит символ `@` и хотя бы одну точку после него. Собери и выведи сообщение через f-строку: `"Login: <email>, password length: <N>"`.
3. **Ближе к практике.** Дана строка лога `log = "  [ERROR] status=500 duration=1234ms  "`. Убери пробелы по краям функцией `.strip()`. Проверь через `in`, что в строке есть подстрока `"ERROR"`. Вырежи число миллисекунд между `"duration="` и `"ms"` (используй `.find()` и срезы), переведи его в секунды и выведи одной f-строкой с двумя знаками после запятой: `"Duration: 1.23 sec"`.
4. **Со звёздочкой.** Есть значение, "пришедшее из файла", с лишним переносом строки на конце: `raw_value = "expected_result\n"` и эталонное значение `expected = "expected_result"`. Сохрани в `raw_equal` результат сравнения `raw_value == expected` без какой-либо обработки — он должен получиться `False`. Затем сохрани в `stripped_equal` результат сравнения того же `raw_value`, но со `.strip()`, с `expected` — он должен получиться `True`. Объясни себе, почему одна и та же пара строк даёт разный результат сравнения.
