# 0.2. Числа, логика и сравнения

## Зачем это нужно

Проверка ожидаемого результата почти всегда сводится к сравнению чисел: код ответа сервера, время выполнения запроса, количество элементов в списке. А булева логика (`and`, `or`, `not`) — это то, из чего потом строятся условия и `assert`-ы в тестах.

## Теория

### Числа

В Python два основных числовых типа: `int` (целые) и `float` (вещественные). Диапазон `int` практически не ограничен. Базовые арифметические операторы:

| Оператор | Смысл | Пример |
|---|---|---|
| `+` `-` `*` | сложение, вычитание, умножение | `2 + 3` |
| `/` | деление, **всегда** возвращает `float` | `8 / 2` → `4.0` |
| `//` | целочисленное деление (округление вниз) | `7 // 2` → `3` |
| `%` | остаток от деления | `10 % 3` → `1` |
| `**` | возведение в степень | `2 ** 10` → `1024` |

Приоритет операций такой же, как в математике: сначала `**`, потом `*`, `/`, `//`, `%`, потом `+`, `-`. Скобки меняют порядок вычислений. Есть один частый сюрприз: при делении отрицательных чисел `//` и `%` округляются "в сторону минус бесконечности", а не к нулю: `-7 // 2` даёт `-4`, а не `-3`.

Сокращённые операторы присваивания экономят строки: `i += 1` вместо `i = i + 1`, аналогично `-=`, `*=`, `/=`.

Функция `round()` округляет число, но не по школьным правилам, а по **банковскому округлению** — до ближайшего чётного при равном расстоянии: `round(2.5)` → `2`, `round(3.5)` → `4`. У неё есть второй параметр — количество знаков после запятой: `round(3.14159, 2)` → `3.14`.

Для более сложной математики есть модуль `math`:

```python
import math

math.ceil(4.1)    # 5 — округление вверх
math.floor(4.9)   # 4 — округление вниз
math.sqrt(49)     # 7.0
math.pi           # 3.141592653589793
```

### Логический тип и сравнения

Тип `bool` — это `True`/`False`. Операторы сравнения:

```
<   >   <=   >=   ==   !=
```

Обрати внимание: `==` — сравнение, `=` — присваивание, это разные операторы, и путаница между ними — классическая ошибка новичков.

Составные условия строятся через `and`, `or`, `not`. Приоритет: `not` выше, чем `and`, а `and` выше, чем `or` — то есть `not` выполняется первым. Python также позволяет "математическую" запись диапазона:

```python
-2 <= y <= 5   # эквивалент y >= -2 and y <= 5
```

Функция `bool()` приводит любое значение к `True`/`False` по правилу "пустое — ложь": `0`, `""`, `[]`, `{}`, `None` — все дают `False`, всё остальное — `True`. Это правило часто используется неявно, например в условии `if some_list:` вместо `if len(some_list) > 0:`.

## Пример

```python
price = 1999.99
discount_percent = 15

discounted_price = round(price * (100 - discount_percent) / 100, 2)
print(discounted_price)  # 1699.99

expected_status = 200
actual_status = 201
is_success = 200 <= actual_status < 300
print(is_success)  # True — 201 тоже "успешный" HTTP-код

# сравнение вещественных чисел "в лоб" опасно из-за погрешности округления
result = 0.1 + 0.2
print(result == 0.3)                  # False, неожиданно!
print(abs(result - 0.3) < 1e-9)       # True — правильный способ сравнить float
```

## Частые ошибки

- Сравнивать вещественные числа через `==` — из-за особенностей хранения `float` в памяти `0.1 + 0.2 != 0.3`. Сравнивай через допустимую погрешность (`abs(a - b) < 1e-9`).
- Путать `/` и `//` — `/` всегда даёт `float`, даже `10 / 2` → `5.0`.
- Забывать про банковское округление в `round()` и удивляться, почему `round(0.5)` — это `0`, а не `1`.
- Писать `if flag == True:` вместо `if flag:` — работает, но не по стилю Python.

## Мини-задание

Дан заказ на сумму `price = 2450` рублей со скидкой `discount = 12` (в процентах). Посчитай итоговую сумму с округлением до копеек. Затем напиши составное условие, проверяющее, что HTTP-код `actual_status` находится в диапазоне `[200; 299]` **или** равен `304`, и выведи результат как `bool`.
