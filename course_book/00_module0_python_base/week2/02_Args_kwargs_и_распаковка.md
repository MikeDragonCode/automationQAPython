# 0.9. *args, **kwargs, распаковка, лямбды

## Зачем это нужно

Когда начнёшь читать код фреймворков (pytest, requests, Playwright) — везде будут встречаться сигнатуры вроде `def request(method, url, **kwargs)`. Не понимая `*args`/`**kwargs`, невозможно разобраться, что вообще можно передать в такую функцию. Лямбды же — стандартный инструмент для сортировки и фильтрации данных одной строкой.

## Теория

### *args — произвольное число позиционных аргументов

Если поставить `*` перед именем параметра, все "лишние" позиционные аргументы соберутся в кортеж:

```python
def join_path(*parts):
    return "/".join(parts)

join_path("api", "v1", "users")   # 'api/v1/users' — 3 аргумента, а не 1 список
```

Внутри функции `parts` — обычный кортеж, с ним можно делать всё то же, что с любым кортежем.

### **kwargs — произвольное число именованных аргументов

Аналогично, но для именованных аргументов — они собираются в словарь:

```python
def build_query(**params):
    return "&".join(f"{key}={value}" for key, value in params.items())

build_query(page=1, per_page=20)   # 'page=1&per_page=20'
```

Оба варианта можно комбинировать в одной функции — но строго в таком порядке: сначала обычные позиционные параметры, потом `*args`, потом именованные параметры со значением по умолчанию, потом `**kwargs`:

```python
def make_request(method, url, *args, timeout=30, **kwargs):
    print(method, url, args, timeout, kwargs)

make_request("GET", "/users", verbose=True, retries=3)
# GET /users () 30 {'verbose': True, 'retries': 3}
```

Если в сигнатуре после `*args` (или просто одинокой `*`) идут ещё параметры — их можно передать **только по имени**, позиционно уже не получится. Это частый приём в реальных библиотеках, чтобы заставить вызывающий код быть явным.

### Параметры только по имени (keyword-only)

Разберём эту идею отдельно, потому что на первый взгляд она выглядит странно. Возьмём функцию из примера выше:

```python
def make_request(method, url, *args, timeout=30, **kwargs):
    print(method, url, args, timeout, kwargs)
```

`timeout` стоит после `*args` — значит передать его позиционно, третьим аргументом, уже нельзя, только по имени `timeout=...`:

```python
make_request("GET", "/users", timeout=5)   # OK
make_request("GET", "/users", 5)           # 5 уйдёт в args, а не в timeout!
```

Второй вызов не упадёт с ошибкой, но и не сделает того, что ты, скорее всего, имел в виду: `5` просто попадёт в кортеж `args`, а `timeout` останется равен `30` по умолчанию. Чтобы явно *запретить* передавать параметр позиционно и заставить вызывающий код быть однозначным, перед нужными параметрами ставят одинокую `*` (без имени после неё), даже если `*args` вообще не нужен:

```python
def make_request(method, url, *, timeout=30):
    print(method, url, timeout)

make_request("GET", "/users", timeout=5)   # OK
make_request("GET", "/users", 5)           # TypeError: takes 2 positional arguments but 3 were given
```

Здесь `*` без имени — не сбор аргументов, а просто разделитель: всё, что после неё, обязано передаваться по имени. Такой приём часто встречается в зрелых библиотеках именно для того, чтобы вызывающий код нельзя было написать двусмысленно.

### Зачем `**kwargs` нужен в чужом коде

Самое частое практическое применение `*args`/`**kwargs` — не сбор произвольных данных, а **прозрачная передача** аргументов дальше, в другую функцию, без необходимости знать заранее, что именно в неё передадут:

```python
def call_and_log(func, *args, **kwargs):
    print(f"Calling {func.__name__} with args={args}, kwargs={kwargs}")
    return func(*args, **kwargs)

call_and_log(max, 3, 7, 2)                 # Calling max with args=(3, 7, 2), kwargs={}
call_and_log(round, 3.14159, ndigits=2)    # Calling round with args=(3.14159,), kwargs={'ndigits': 2}
```

`call_and_log` ничего не знает о том, что за функцию ей передадут и с какими аргументами — она просто принимает всё через `*args, **kwargs` и передаёт дальше через `func(*args, **kwargs)`. Именно так устроены сигнатуры вроде `requests.request(method, url, **kwargs)`, упомянутой в начале урока: `**kwargs` там — это способ принять любой набор именованных параметров (`timeout`, `headers`, `params`, ...) и передать их дальше, во внутреннюю реализацию, не перечисляя все возможные варианты явно.

### Упаковка и распаковка коллекций

Тот же символ `*` умеет работать и в обратную сторону — **распаковывать** коллекцию в отдельные аргументы:

```python
numbers = (5, 3, 8)
print(max(*numbers))   # эквивалент print(max(5, 3, 8))

def get_v(a, b, c):
    return a * b * c

dimensions = (2, 3, 4)
get_v(*dimensions)   # 24
```

Для словарей та же идея работает с `**` — распаковка пар ключ-значение в именованные аргументы:

```python
user_data = {"username": "ivan", "age": 25}

def create_user(username, age):
    return f"{username}, {age}"

create_user(**user_data)
```

Похожий приём используют, чтобы объединить два словаря в один:

```python
defaults = {"timeout": 30, "retries": 3}
overrides = {"retries": 5}
config = {**defaults, **overrides}   # {'timeout': 30, 'retries': 5}
```

### Лямбда-функции

Лямбда — короткая безымянная функция из одного выражения:

```python
square = lambda x: x ** 2
square(5)   # 25
```

Лямбды почти никогда не объявляют "про запас" в переменную (для этого есть обычный `def`) — их главное применение — передавать "на лету" в качестве аргумента другим функциям, например для сортировки (см. урок 0.14):

```python
users = [{"name": "Ivan", "age": 25}, {"name": "Olga", "age": 30}]
sorted(users, key=lambda u: u["age"])
```

В лямбде можно записать только одно выражение — ни `if/else`-блоков, ни нескольких строк, ни присваиваний. Если логика не помещается в одну строку — это сигнал, что нужна обычная функция через `def`.

## Пример

```python
def log_message(*parts, sep=" | "):
    return sep.join(str(p) for p in parts)


print(log_message("2024-01-15", "ERROR", "connection failed"))
# 2024-01-15 | ERROR | connection failed

print(log_message("INFO", "started", sep=" -> "))
# INFO -> started

# распаковка при вызове
timestamps = ("12:00", "12:05", "12:10")
print(log_message(*timestamps))
# 12:00 | 12:05 | 12:10

is_even = lambda n: n % 2 == 0
print(list(filter(is_even, [1, 2, 3, 4, 5, 6])))
# [2, 4, 6]
```

## Частые ошибки

- Пытаться передать именованный аргумент туда, где ожидается только `*args`, и наоборот.
- Засовывать в лямбду многострочную логику — она туда физически не помещается, будет `SyntaxError`.
- Путать `*args` (кортеж позиционных) и `**kwargs` (словарь именованных) местами в объявлении функции.
- Нарушать порядок параметров: обычные → `*args` → именованные со значением по умолчанию → `**kwargs`.
