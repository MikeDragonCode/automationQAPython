# Модуль 5. Allure и отчётность (неделя 11)

К этому моменту у тебя уже есть тесты в общем репозитории (API — модуль 3, UI — модуль 4). Проблема в том, что "тест упал" сам по себе почти ничего не говорит: непонятно, на каком шаге, с каким запросом, с каким скриншотом. Allure превращает список зелёных/красных точек в отчёт, по которому можно разобраться в падении, не перечитывая код теста.

Модуль написан заново (в исходном курсе `stepik-api-testing-advanced` соответствующий раздел оказался пустой заглушкой — см. `ROADMAP.md`), но опирается на уже готовую, проверенную интеграцию Allure в `boilerplate/`.
