# Модуль 2. Git и командная работа

Неделя 5 и дальше — постоянно, до конца курса.

## Что меняется с этого модуля

Модули 0–1 ты проходил соло: писал код, сдавал файлы. Начиная с этого модуля вводится
**общий репозиторий** — `boilerplate/`, реальный стартовый фреймворк этого курса
(`pytest` + `requests` + `playwright`). Ты форкаешь его один раз, и с этого момента
**каждое домашнее задание — это Pull Request в общий репозиторий**, а не отдельный проект.

Так строится работа в любой реальной QA automation команде: тесты живут в общем
репозитории, изменения проходят через ветки, PR и ревью, а не пишутся "в стол".
