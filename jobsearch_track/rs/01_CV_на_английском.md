# RS. CV на английском

## Зачем это нужно

На сербском и международном рынке резюме на русском не рассматривается почти нигде за пределами русскоязычных компаний. CV на английском — не перевод русского резюме дословно, а отдельный документ со своими принятыми форматами.

## Структура CV (принятый международный формат отличается от привычного российского резюме)

1. **Header.** Имя, роль ("QA Automation Engineer"), контакты, ссылка на LinkedIn и GitHub — без фото (в отличие от принятого в РФ формата, на международном рынке фото в CV обычно не ожидается и иногда даже избегается из-за политики non-discrimination).
2. **Summary (2-3 строки).** Кратко: кто ты, какой стек, что ищешь. Пример: "Junior QA Automation Engineer with hands-on experience in Python, pytest, Playwright and API testing (requests, Pydantic). Comfortable working in a team repository with Git/PR workflow and CI pipelines."
3. **Skills.** Списком, по категориям: Languages (Python), Testing (pytest, Playwright, API testing, Allure), Tools (Git, GitHub Actions/GitLab CI), Soft skills — по минимуму, международные CV меньше внимания уделяют soft skills в резюме джуниора, больше — на самом интервью.
4. **Experience/Projects.** Так же, как в русскоязычном треке (см. `ru/01_Резюме.md`) — конкретные формулировки на основе реальных PR, но на английском. Использовать action verbs (Implemented, Built, Configured, Reviewed), избегать пассивного залога.
5. **Education.** Кратко, в конце.

## Частые ошибки при переводе резюме на английский

- Дословный перевод русских формулировок ("занимался написанием автотестов") вместо естественных английских ("wrote and maintained automated tests") — резюме, переведённое машинально, заметно рекрутеру.
- Использование российского формата с фото и датой рождения — на международном рынке это не ожидается и иногда выглядит нестандартно.
- Не указывать уровень английского явно, если он не C1+ — честная оценка (B1/B2) с указанием того, что достаточно для рабочей переписки и код-ревью, воспринимается лучше, чем невыполненное молчаливое "по умолчанию свободно".

## Мини-задание

Переведи свой раздел "Опыт" из русскоязычного резюме (`ru/01_Резюме.md`, мини-задание) на английский, используя action verbs, и попроси одногруппника с более уверенным английским проверить формулировки.
