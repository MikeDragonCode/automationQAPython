# Job-search трек

Параллельный трек, стартует с модуля 6 (не блокирует техническую часть курса) — за исключением трека для Сербии, который стартует раньше (с модуля 3), потому что языковой барьер требует больше времени на разгон.

- [`ru/`](ru/) — резюме, hh.ru/Habr Career, разбор вакансий junior QA automation в РФ.
- [`rs/`](rs/) — резюме на английском, LinkedIn, технический английский — для студентов, ориентированных на рынок Сербии/международный рынок.

## Почему треки разные

Требования к junior QA automation в РФ и на международном/сербском рынке отличаются не по сути навыков (стек тот же — Python, pytest, Playwright, API), а по формату подачи: язык резюме, платформы поиска, ожидания от технического интервью на английском. Разделение треков — не про разный уровень, а про разную "упаковку" одних и тех же навыков.
