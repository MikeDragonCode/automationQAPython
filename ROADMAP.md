# Roadmap курса

14 недель, 8 модулей. С модуля 2 работа идёт в общем репозитории (`boilerplate/`).
Параллельно, с модуля 6 (не блокирует техническую часть) — джобсерч-трек (`jobsearch_track/`), отдельный для РФ и Сербии.

| Модуль | Недели | Тема | Источник материала | Итог модуля |
|---|---|---|---|---|
| 0 | 1–2 | Python-база: синтаксис, типы, функции, файлы/JSON, базовое ООП | `stepik-dobry-python-course` (главы 01–10) | скрипт-парсер публичного API |
| 1 | 3–4 | pytest как среда: fixtures, conftest, parametrize, маркеры, assert | `stepik-playwright-ui-testing` (05), собственный материал | 10–15 тестов на простых утилитах |
| 2 | 5+ | Git и командная работа. Старт общего репозитория | `stepik-api-testing-advanced` (04) | первый смёрженный PR в общий репо |
| 3 | 6–7 | API-тестирование на `requests`: методы, статусы, auth, Pydantic, API-клиент | `stepik-api-testing-advanced` (05–07, HTTPX→requests) | 5–7 API-тестов, PR к существующему api-модулю |
| 4 | 8–10 | Playwright + Page Object Model | `stepik-playwright-ui-testing` (01–07) | 2–3 UI-теста, PR в общий репозиторий |
| 5 | 11 | Allure: шаги, título, вложения, отчёт | написано заново (источник — заглушка) | все тесты студента снабжены allure-шагами |
| 6 | 12 | CI на уровне пользователя: чтение pipeline, диагностика падений | написано заново (источник — заглушка) | студент сам чинит сломанный тест по логам CI |
| 7 | 13–14 | Финальный спринт: багфиксы, ревью, рефакторинг чужих тестов | — | 10+ PR с ревью в истории каждого студента |

## Почему источники по Allure/CI/API-практике написаны заново

При выгрузке `stepik-api-testing-advanced` разделы 8–15 (Pytest-практика, Allure, улучшение автотестов, CI/CD, покрытие, AI Review) оказались заблокированы Stepik progression-gate — в файлах только заголовки уроков, без содержимого. Модули 5 и 6 этого курса, а также практическая часть модуля 3, написаны самостоятельно с опорой на структуру из `stepik-playwright-ui-testing` (там есть рабочий раздел про pytest+Playwright) и на стандартные практики индустрии.

## Job-search трек (параллельно, с модуля 6)

- **RU:** резюме, hh.ru/Habr Career, разбор вакансий junior QA automation.
- **RS (Сербия):** резюме на английском раньше и активнее, LinkedIn, английский для технического собеседования — стартует с модуля 3, а не с модуля 6, т.к. языковой барьер требует больше времени на разгон.
