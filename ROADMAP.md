# Roadmap курса

14 недель, 8 модулей. С модуля 2 работа идёт в общем репозитории (`boilerplate/`).
Параллельно, с модуля 6 (не блокирует техническую часть) — джобсерч-трек (`jobsearch_track/`), отдельный для РФ и Сербии.

| Модуль | Недели | Тема | Итог модуля |
|---|---|---|---|
| 0 | 1–2 | Python-база: синтаксис, типы, функции, файлы/JSON, базовое ООП | скрипт-парсер публичного API |
| 1 | 3–4 | pytest как среда: fixtures, conftest, parametrize, маркеры, assert | 10–15 тестов на простых утилитах |
| 2 | 5+ | Git и командная работа. Старт общего репозитория | первый смёрженный PR в общий репо |
| 3 | 6–7 | API-тестирование на `requests`: методы, статусы, auth, Pydantic, API-клиент | 5–7 API-тестов, PR к существующему api-модулю |
| 4 | 8–10 | Playwright + Page Object Model | 2–3 UI-теста, PR в общий репозиторий |
| 5 | 11 | Allure: шаги, título, вложения, отчёт | все тесты студента снабжены allure-шагами |
| 6 | 12 | CI на уровне пользователя: чтение pipeline, диагностика падений | студент сам чинит сломанный тест по логам CI |
| 7 | 13–14 | Финальный спринт: багфиксы, ревью, рефакторинг чужих тестов | 10+ PR с ревью в истории каждого студента |

## Job-search трек (параллельно, с модуля 6)

- **RU:** резюме, hh.ru/Habr Career, разбор вакансий junior QA automation.
- **RS (Сербия):** резюме на английском раньше и активнее, LinkedIn, английский для технического собеседования — стартует с модуля 3, а не с модуля 6, т.к. языковой барьер требует больше времени на разгон.
