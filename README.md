# QA Automation Course (Python)

Курс подготовки QA Automation Engineer с нуля до уровня "готов к первой работе": Python → pytest → Git/командная работа → API-тестирование → Playwright/UI → Allure → CI/CD → работа над тикетами в общем репозитории.

Формат: 14 недель, 8 модулей + постоянный параллельный джобсерч-трек с недели 6.

## Структура репозитория

```
qa-automation-course/
├── ROADMAP.md               — недельный план, модули, milestones
├── STYLE_GUIDE.md           — единый формат урока (для авторов и для проверки консистентности)
├── course_book/             — теория + код + задания по модулям/неделям
│   ├── 00_module0_python_base/
│   ├── 01_module1_pytest_env/
│   ├── 02_module2_git_teamwork/
│   ├── 03_module3_api_testing/
│   ├── 04_module4_playwright_pom/
│   ├── 05_module5_allure/
│   ├── 06_module6_ci/
│   └── 07_module7_final_sprint/
├── boilerplate/              — "общий репозиторий": стартовый фреймворк pytest+requests+playwright,
│                                который студенты форкают начиная с модуля 2
└── jobsearch_track/          — резюме/поиск работы/английский, отдельно для РФ и Сербии
```

## Как это использовать

1. Модули 0–1 студент проходит соло (`course_book/00_...`, `01_...`), сдаёт домашки как файлы.
2. С модуля 2 студент форкает `boilerplate/` в свой GitHub/GitLab — с этого момента все домашки оформляются как PR в общий репозиторий.
3. Модули 3–5 — это PR к уже существующему `boilerplate/` (API-клиент, Page Object'ы, Allure-шаги), а не вещи "с нуля".
4. Модуль 6 — студент учится читать CI, а не писать pipeline с нуля.
5. Модуль 7 — "боевые" тикеты: багфиксы, ревью, рефакторинг чужого кода в общем репозитории.
